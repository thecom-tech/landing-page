Ein sicherer Arbeitsbereich für KI-Programmieragenten

Mit Glonys setzen Teams KI-Programmieragenten sicher auf ihren eigenen Repositorys ein. Sie verwenden Ihren eigenen Schlüssel Ihres KI-Anbieters, die Agenten arbeiten in isolierten Umgebungen, und jedes Ergebnis kommt als Pull Request, den eine Person prüft.

Was Glonys ist

Ein Ort, an dem Teams KI-Programmieragenten an echtem Code arbeiten lassen, ohne die Kontrolle über Schlüssel, Code oder die endgültige Entscheidung abzugeben.

  • Ihre Repositorys

    Die Agenten arbeiten an den Repositorys, die Sie verbinden, und an nichts anderem.

  • Ihr Schlüssel für den KI-Anbieter

    Jede Person bringt ihren eigenen Schlüssel ihres KI-Anbieters mit (BYOK). Die Geschäftsbeziehung und die Abrechnung mit Ihrem Anbieter bleiben bei Ihnen.

  • Isolierte Umgebungen

    Jeder Agent läuft in seiner eigenen isolierten Umgebung, getrennt von anderer Arbeit.

  • Eine Person prüft

    Ergebnisse kommen als Pull Requests. Nichts wird gemergt, bevor jemand aus Ihrem Team es geprüft hat.

So funktioniert es

Drei Schritte vom Repository zur geprüften Änderung.

  1. Repository verbinden

    Wählen Sie das Repository, an dem die Agenten arbeiten sollen.

  2. Schlüssel hinzufügen

    Fügen Sie Ihren eigenen Schlüssel Ihres KI-Anbieters hinzu. Er wird den Agenten nie offengelegt.

  3. Agent starten und PR prüfen

    Beschreiben Sie die Aufgabe, starten Sie einen Agenten und prüfen Sie den Pull Request, den er öffnet.

Grundsätze

Die Zusagen, auf denen das Produkt aufgebaut wird.

  • Ihre Schlüssel gehören Ihnen

    Ihre Schlüssel für den KI-Anbieter werden den Agenten nie offengelegt.

  • Standardmäßig isoliert

    Agenten laufen von Anfang an in isolierten Umgebungen, nicht als Zusatz.

  • Keine Werbung, kein Datenverkauf

    Wir zeigen keine Werbung und verkaufen keine Daten.

  • Ihr Code ist kein Trainingsmaterial

    Ihr Code wird nie zum Trainieren von Modellen verwendet.

Über uns

Glonys ist ein unabhängiges, eigenfinanziertes Unternehmen. Es wurde 2026 von einer einzelnen Person gegründet und hat seinen Sitz in Bogotá, Kolumbien. Das Produkt befindet sich in einer privaten Beta und ist noch in Entwicklung.
