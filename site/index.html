A secure workspace for AI coding agents

Glonys lets teams run AI coding agents on their own repositories, safely. You bring your own AI provider key, agents work in isolated environments, and every result arrives as a pull request that a person reviews.

What Glonys is

A place for teams to put AI coding agents to work on real code without giving up control over keys, code or the final decision.

  • Your repositories

    Agents work on the repositories you connect, and nothing else.

  • Your AI provider key

    Each person brings their own key from their AI provider (BYOK). You keep the relationship and the billing with your provider.

  • Isolated environments

    Each agent runs in its own isolated environment, separate from other work.

  • A person reviews

    Results arrive as pull requests. Nothing is merged until someone on your team reviews it.

How it works

Three steps, from repository to reviewed change.

  1. Connect your repository

    Choose the repository you want agents to work on.

  2. Add your key

    Add your own AI provider key. It is never exposed to the agents.

  3. Launch an agent and review its PR

    Describe the task, launch an agent and review the pull request it opens.

Principles

The commitments the product is being built around.

  • Your keys are yours

    Your AI provider keys are never exposed to the agents.

  • Isolation by default

    Agents run in isolated environments from the start, not as an add-on.

  • No ads, no data sales

    We do not show ads and we do not sell data.

  • Your code is not training data

    Your code is never used to train models.
